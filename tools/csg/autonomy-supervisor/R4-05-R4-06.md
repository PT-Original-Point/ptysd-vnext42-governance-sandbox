# R4-05 / R4-06 scheduler and anti-loop candidate

`scheduler.mjs` makes the work-conserving rule mechanical: a WAITING_EXTERNAL lane cannot occupy the executor while any READY lane exists. Only one RUNNING lane is allowed.

`fingerprint.mjs` computes a deterministic SHA-256 over Project/Directory/control/checkpoint/run/accepted-source/mailbox/Factory observations. The controller uses this to suppress repeated handoff/snapshot/test/non-idempotent dispatch on unchanged durable state.

These modules are pure decision helpers. They are not a second canonical state store and do not mutate providers.
